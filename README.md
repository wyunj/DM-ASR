# DM-ASR: Diarization-aware Multi-speaker ASR with Unified Offline and Online Decoding with Large Language Models

## 📖 Introduction

**DM-ASR** is a diarization-aware multi-speaker ASR framework built on large language models. Our DM-ASR system can support both **online** and **offline** inference within a unified framework.

The paper is available at: [https://arxiv.org/abs/2604.22467](https://arxiv.org/abs/2604.22467)
